# CI Rules

## Workflow Overview

| Workflow                | Trigger       | What it checks                              |
| ----------------------- | ------------- | ------------------------------------------- |
| `ci.yml`                | push/PR       | format, lint, typecheck, test, build, guard |
| `e2e.yml`               | push/PR       | Playwright tests in mock mode               |
| `storybook.yml`         | push/PR       | Storybook build                             |
| `dependency-review.yml` | PR only       | new dependency vulnerabilities              |
| `codeql.yml`            | push/schedule | security analysis                           |

## `pnpm check`

Running `pnpm check` locally runs the same checks as CI:

```bash
pnpm format:check  # Prettier
pnpm lint          # ESLint
pnpm typecheck     # TypeScript
pnpm test          # Vitest
pnpm build         # Vite build
pnpm guard:forbidden-changes  # Safety checks
```

## Rules

1. **Never bypass CI** with `--no-verify` or skip-CI commits.
2. **Fix root cause** — don't suppress lint/type errors.
3. **Do not delete workflow files** — they are protected by `guard:forbidden-changes`.
4. **All checks must pass** before merging a PR.
5. **CI runs in mock mode** (`VITE_MOCK_API=true`) — no real backend needed.
