# 1. このテンプレートの概要

## このテンプレートは何か

このリポジトリは、**デザイナーと AI が協力して React フロントエンドを安全に開発するためのテンプレート**です。

エンジニアが少ない体制でも、デザイナーが画面単位で AI（Claude Code / Cursor）に依頼し、品質を保ちながら開発を進められるよう設計されています。

## 役割分担

| 担当                       | 役割                                           |
| -------------------------- | ---------------------------------------------- |
| リードエンジニア           | バックエンド（rapid-go）とインフラの設計・構築 |
| デザイナー                 | AI への依頼・デザイン確認・動作確認            |
| AI（Claude Code / Cursor） | コードの実装・テスト・Storybook の追加         |

デザイナーは「何を作るか」を決めて AI に伝えるのが主な役割です。コードを書く必要はありません。

## アプリの構成

| アプリ | URL                   | 用途             |
| ------ | --------------------- | ---------------- |
| admin  | http://localhost:3001 | 管理画面         |
| web    | http://localhost:3000 | 一般ユーザー向け |
