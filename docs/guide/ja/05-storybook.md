# 5. Storybook で画面を確認する

## Storybook とは

Storybook は、画面やコンポーネントのすべての「状態」をブラウザで一覧できるツールです。

実際のバックエンドに接続しなくても、以下の状態を確認できます:

| 状態           | 内容                             |
| -------------- | -------------------------------- |
| 通常表示       | データが正常に読み込まれた状態   |
| 読み込み中     | ローディングスピナーが表示される |
| エラー         | API エラーが発生した状態         |
| 空             | データが0件の状態                |
| スマートフォン | 小さい画面でのレイアウト         |

## 起動方法

```bash
pnpm storybook
```

ブラウザで http://localhost:6007 を開きます。

## 使い方

1. 左のサイドバーからコンポーネントや画面を選びます。
2. 上部の **Stories** タブから確認したい状態を選びます。
3. 右の **Addons** パネルでビューポートを切り替えて画面サイズを変えられます。

## 画面サイズの確認

スマートフォン表示を確認するには、Storybook のビューポート切り替えを使います。

主に確認するサイズ:

| サイズ       | 幅     |
| ------------ | ------ |
| モバイル     | 375px  |
| タブレット   | 768px  |
| デスクトップ | 1280px |

## 新しい画面の Storybook を確認する

AI が画面を実装した後、Storybook に新しい story が追加されています。

確認すべき状態:

- [ ] 通常表示が正しく見える
- [ ] 読み込み中スピナーが表示される
- [ ] エラーメッセージが表示される
- [ ] データが空の場合のメッセージが表示される
- [ ] モバイルサイズで画面が崩れていない
